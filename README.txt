MOMA SST V11
Gestión de Inspecciones de Seguridad y Salud en el Trabajo

Cambios de V11:
- Se eliminan Sector y Sección de la captura de la inspección.
- Morango S.A.S.: campo específico para indicar Planta o Parte administrativa.
- Somos Masa S.A.S.: campo específico para indicar el Punto de Masa.
- Se agregan campos independientes y obligatorios de Área y Ubicación.
- Se mantienen las evidencias por ítem, cámara/galería, hallazgos, aprobación COPASST e informe.
- Morango y Somos Masa conservan sus checklists independientes.

Para publicar: el archivo index.html debe quedar en la raíz del repositorio de GitHub Pages, junto con CONFIGURACION_EMPRESAS.json.
